A is correct. Prompt caching stores the repeated start of a prompt, here the system prompt, so later requests read it from the cache for less money and less time.

Provisioned Throughput reserves model capacity, but every request still processes the full prompt. max_tokens only caps the length of the reply. Batch inference is cheaper, but it runs asynchronously, so it can’t serve a live assistant.
